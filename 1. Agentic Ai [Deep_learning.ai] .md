![alt text](<images_1. Agentic Ai [Deep_learning.ai]/image38.png>) 

![alt text](<images_1. Agentic Ai [Deep_learning.ai]/image39.png>)
First LLM generated stacked bar plot (not easy way to visualize things, doesn't look like a good plot).
Give V1 of the code and the plot , feed it into a multimodal model (which accept image inputs),
ask it to examine the image generated by code and tell to come up with better visualization. (critique the image/ review the image)

Reasoning model for reflection works better than non-reasoning model.
Reflection -> Initial model , pass the output to a reasoning model(for critique/review) and repeat till satisfied.
